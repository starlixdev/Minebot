# Changelog

## 2.1.1-java

Packaged release included in this repository.

- Loads local Java bots from per-bot JAR files.
- Accepts bot providers registered by companion Paper plugins.
- Supports start, stop, reload, validation, and runtime status operations.
- Connects bots to Discord gateway and REST APIs.
- Handles slash commands, interactions, replies, follow-ups, deferrals, and presence.
- Exposes Minecraft commands, broadcasts, snapshots, and event delivery.
- Provides asynchronous HTTP requests with configurable limits and timeouts.
- Stores per-bot data in JSON.
- Exposes structured console log subscriptions.
- Dispatches bot work through a bounded serial runtime and provides scheduling helpers.
